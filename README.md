# Poornachandratejasvi Laxman Bhattar — Personal Research Website

A responsive, static academic homepage designed for GitHub Pages.

## Sections
- About
- Research themes and featured work
- Publications
- Packages / open-source projects (two public repositories shown on the GitHub profile screenshot)
- Education
- Experience
- Skills
- Journey
- Get in touch

## Open-source projects shown
1. **MinTEJ** — a minimalistic integrated development environment for Julia, with small programs and supporting files for editing and managing code.
2. **pAST.jl** — a Julia program for Abstract Syntax Tree (AST) visualisation.

The package cards link to the corresponding public GitHub repositories and include simple workflow diagrams. They are explicitly described as public repositories, not as GitHub Packages registry releases.

## Publish on GitHub Pages
1. Extract the ZIP archive.
2. Upload the *contents* of the `pctejasvi-research-site` folder to the root of `PCTejasvi/pctejasvi.github.io`.
3. Commit the files to the `main` branch.
4. In **Settings → Pages**, select **Deploy from a branch**, branch `main`, folder `/ (root)`.

Keep `index.html`, `style.css`, `script.js`, `assets/`, `README.md`, and `SOURCES.md` in the repository root (with the favicon inside `assets/`).

## Editing
- Update text and links in `index.html`.
- Adjust the aubergine / ivory palette and responsive layout in `style.css`.
- Navigation and publication filters are handled in `script.js`.

The site uses no build step or package installation. Google Scholar, Scopus and GitHub are external links.
